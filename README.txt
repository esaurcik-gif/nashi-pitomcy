НАШИ ПИТОМЦЫ — ОФЛАЙН PWA

1. Не открывайте index.html двойным щелчком: для Service Worker нужен HTTPS или localhost.
2. Разместите всю папку на HTTPS-хостинге (например, GitHub Pages) или запустите локальный сервер.
3. Откройте адрес в Chrome на Android, дождитесь полной загрузки, затем выберите меню браузера -> Установить приложение / Добавить на главный экран.
4. После первого успешного открытия и установки приложение кэширует файлы интерфейса. Проверьте офлайн-режим, включив авиарежим.
5. Данные и фото хранятся в IndexedDB конкретного браузера/устройства.
6. Регулярно нажимайте «Скачать резервную копию» и храните JSON-файл отдельно.
7. «Восстановить из файла» заменяет текущую базу данными из резервной копии.

ВАЖНО:
- Это офлайн-приложение для одного устройства/профиля браузера. Автоматической синхронизации между телефонами нет.
- Удаление данных сайта/браузера может удалить базу. Экспортируйте резервные копии.
- При большом количестве фото доступный объём зависит от устройства и браузера.
- Приложение не подключает внешний шрифт для работы: системный шрифт используется как запасной.
